# MonoCode UI/UX audit

Static audit run on 2026-10-08 against branch `mc/orch-ec158f036ed2` (HEAD `e691188`). The review was read-only: no source file was changed. Context for the review is in `PRODUCT.md` and `DESIGN.md` at the repository root.

## Scope and Coverage

**Mode:** `better-interface` full mode, merged with the impeccable `audit` dimensions. The user raised the finding cap to 30. This report has 25 findings.

**Scope:** session transcript and composer (`src/features/sessions`), the app shell (`src/app/shell`: project rail, session sidebar, title-bar tabs, Windows/Linux menu bar), settings (`src/features/settings`), inbox (`src/features/inbox`), file tree and editor tabs (`src/features/files`, `src/features/workspace`), source control (`src/features/source-control`), Monos (`src/features/monos`), the quick composer (`src/features/quick-composer`), and the shared layer (`src/styles/index.css`, `src/shared/ui`).

**Stack and conventions:** Tauri 2 desktop shell. React 19 and TypeScript. Tailwind CSS v4 with tokens in the `@theme` block of `src/styles/index.css`. Colors are HSL and hex with `color-mix()` alpha tiers. Chrome icons come from Hugeicons through `src/shared/ui/icons.tsx` (default stroke 1.75); file-type icons come from `react-material-icon-theme`. There is no component library beyond the local `src/shared/ui` primitives. The window has a minimum size of 800 × 520 (`src-tauri/tauri.conf.json`).

**Boundary:** this is static analysis only. The app was not launched, so rendered contrast over chat background images and native glass, screen-reader output, and real keyboard traversal are marked **Not verified** in the Verification section. They are not reported as findings. Contrast numbers are computed from the actual token values: dark ground `hsl(240 0% 9%)` = #171717 with ink `hsl(240 0% 92%)` = #ebebeb, and light ground #f7f7f7 with ink #2e2e2e. Tailwind v4 status shades were converted from their OKLCH definitions.
