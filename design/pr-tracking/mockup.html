Inbox · PR detail with stack rail

Sits above the existing PR overview. Merged parents stay in the chain. The health line states the single most urgent fact, drawn from GitHub data. When the chain runs out of room, PRs farthest from the one you're viewing drop to their numbers first; only then does the rail scroll.

Composer chip and sidebar icon states

With no PRs, nothing renders; Create PR stays in the Changes panel. Width is reserved while a PR is confirming, so the header never jumps. Shape repeats every color cue: a filled dot blocks, a ring needs action, a dashed outline or clock means the status may be out of date.

Card states

Persisted snapshots render first. Network trouble degrades to the last known status with a reason and a time, never a blank card.
